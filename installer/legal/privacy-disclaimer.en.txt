Effective and last updated: 11 September 2026 · Version 1.2

LOCAL-FIRST PRIVACY SUMMARY
• The app reads paired-device name, Windows endpoint/container identifiers, available Bluetooth address, device category, connection state, and battery level. It uses these details in memory and does not persist or upload them.
• Settings are stored in %LocalAppData%\BluetoothNotify\settings.json.
• Rotating local technical logs store timestamps, app events, error types, and error messages (up to five files of about 512 KiB). Device names/addresses are not intentionally logged, but operating-system error text could contain local technical details.
• The installer checks Microsoft prerequisites locally and may create a local setup log. It opens Microsoft pages only after permission and sends no installation data to the publisher.
• The static website at https://bluetooth-notify.onrender.com/ sets no cookies and uses no analytics, advertising, accounts, forms, pixels, fingerprinting, or telemetry. It is hosted as a Render static site. Render may process device/IP and infrastructure data under https://render.com/privacy; Render states that static sites do not emit application request logs.
• The unmodified app does not sell, share, rent, upload, profile, or make legally significant automated decisions with personal data. In-memory data disappears on exit. Settings and logs remain until the user deletes them or selects removal during uninstall.
