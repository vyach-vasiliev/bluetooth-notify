# Отчёт о проверке

Дата: 2026-09-08. Среда: Windows 11 x64, .NET SDK 10.0.400, .NET Desktop Runtime 10.0.11, Windows App Runtime 1.8.

## Автоматически проверено

- `dotnet build BluetoothNotify.slnx -c Release` — успешно;
- `dotnet test BluetoothNotify.slnx -c Release` — 65/65 тестов успешно;
- framework-dependent publish для `win-x64` создан в `artifacts/publish/win-x64`;
- smoke-test publish: первый процесс остаётся запущен, второй экземпляр передаёт команду `show` через named pipe и завершается; найден ровно один процесс;
- при показе панели после IPC-команды новых ошибок в журнале нет;
- повторный экземпляр подтверждённо передал одну IPC-команду `show`, после чего завершился; основной экземпляр завершён штатной UI Automation-командой «Выход»;
- WPF tool window проверен через HWND/UI Automation на системном масштабе 200%: карточки растягиваются на всю доступную ширину, refresh имеет hit area 40×40 DIP, footer-кнопки доступны;
- оба read-only индикатора на текущем тестовом ПК видны UI Automation как `ControlType.Text`, не фокусируются и сообщают имя устройства и значение «Подключено»/«Не подключено»;
- EXE содержит собственную иконку 64×64, совпадающую с Bluetooth-логотипом панели; runtime-иконка трея генерируется как увеличенный глиф на прозрачном фоне, без уменьшающей его вложенной плашки;
- процент заряда читается из системного свойства Windows, HFP/PnP fallback и стандартного GATT Battery Service по endpoint или Bluetooth-адресу; если устройство не публикует ни один из источников, интерфейс показывает `—` без декоративной серой шкалы;
- аппаратная проверка HFP/PnP fallback на `Commo Immersive Hands-Free AG` вернула 90%; UI Automation итоговой панели подтвердила `Передают заряд: 1` и `90%`;
- повторная аппаратная проверка показала одновременно HUAWEI FreeBuds 5 (подключено, 100%, цветная шкала) и Commo Immersive (не подключено, последний известный заряд 90%, серая шкала); после уточнения семантики заголовок корректно сообщил `Передают заряд: 1`, исключив отключённое устройство;
- список ограничен высотой двух полных карточек, третья и последующие доступны вертикальной прокруткой;
- системная tooltip tray-иконки отключена через silent notify-icon v3; Win32-проверка после четырёх секунд удержания указателя над значком обнаружила 0 видимых tooltip-окон;
- подготовлены светлая и тёмная 64×64 иконки, а tray-иконка следует выбранной теме приложения и обновляется сразу после изменения настройки; режим «как в системе» следует системной теме приложений;
- при минимальном заряде подключённых устройств 16–29% поверх tray-иконки отображается жёлтый `UpdateStatusDot2` (`EC83`), при 0–15% — красный; при 30–100% или отсутствии актуального заряда точка скрыта, цвет основного Bluetooth-глифа не меняется;
- светлая и тёмная панели визуально проверены после удаления вложенного WPF-скругления: внешний край теперь формируется только DWM и не содержит дублирующей дуги;
- кнопка уведомлений визуально проверена в обоих состояниях: `MobNotificationBell` (`F2A3`) при включённых и `MobSnooze` (`F285`) при выключенных уведомлениях;
- страница настроек проверена внутри исходной панели на русском и английском языках, в светлой и тёмной темах; смена языка и темы применяется без перезапуска;
- английский satellite resource содержит тот же набор пользовательских ключей, что и основной ресурс; автоматический тест предотвращает неполный перевод;
- миграция `settings.json` со схемы 1 на схему 2 сохраняет состояние уведомлений и добавляет язык/тему со значениями «как в системе»;
- нативное tray-меню визуально проверено: «Открыть», «Обновить», «Настройки», «Выход»; пункт «Настройки» присутствует между обновлением и выходом;
- перед уведомлением о подключении выполняется принудительное обновление устройства; toast содержит PNG-иконку приложения через `appLogoOverride`, отдельное название устройства в заголовочной строке и заряд с индикатором `🟢`/`🟡`/`🔴`;
- панель повторно позиционируется после асинхронного изменения высоты, учитывает фактическую область развёрнутой auto-hide панели задач и оставляет от неё безопасный отступ;
- publish содержит 44 application/projection-файла (около 38,2 МБ) и не содержит .NET runtime (`coreclr`, `clrjit`, `hostfxr`, `PresentationFramework`).

Во время smoke-test были обнаружены и исправлены runtime XAML-ошибка TwoWay-binding шкалы батареи, нерастянутый шаблон карточки, первичное размещение по предварительной высоте, отсутствие Automation Peer у индикатора, преждевременное скрытие неактивируемой hover-панели и перекрытие панелью задач после асинхронного обновления. Повторный прогон после исправлений — без новых ошибок.

## Не проверено без физического оборудования/ручного стенда

- фактическое GATT-чтение на конкретных BLE-мыши и клавиатуре;
- объединение реального аудиоустройства с одновременными Classic и LE endpoint;
- toast при реальном disconnect/reconnect;
- Bluetooth adapter off/on, suspend/resume и перезапуск Explorer;
- taskbar на всех четырёх сторонах и два монитора с разными DPI;
- UI Automation через внешний screen reader.

Установщик и его install/update/uninstall-проверки исключены из задачи пользователем.
